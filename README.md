# Portfolio

Personal portfolio site of Michael Kobtsev, Senior Full-Stack Engineer · Tech Lead.

**Live:** https://kobtsev-m.github.io/Portfolio

## Features
- Commercial projects grouped by employer, with real previews, scale and case-study links
- In-page preview popup: project sites open in a near-fullscreen frame; pages that block embedding (Businessware case studies, AMDB) are shown as full-page snapshots
- CV (EN/RU) opens in the same popup
- Light and dark themes, English and Russian (i18next), animations with react-spring

## Stack
React 17, TypeScript, styled-components, react-spring, i18next, GitHub Pages

## Run locally
```bash
yarn install
yarn start      # dev server
yarn deploy     # build and publish to GitHub Pages
```
